# Rotel Amplifier (TCP) для Home Assistant

🇬🇧 [English version](https://github.com/1orgar/ha_rotel_amp/blob/main/README.md)

[![Validate](https://github.com/1orgar/ha_rotel_amp/actions/workflows/validate.yml/badge.svg)](https://github.com/1orgar/ha_rotel_amp/actions/workflows/validate.yml)

[![License](https://img.shields.io/github/license/1orgar/ha_rotel_amp)](https://github.com/1orgar/ha_rotel_amp/blob/main/LICENSE)

Локальное управление усилителями Rotel (RA-1572, RA-1572MKII и другими моделями с тем же TCP-протоколом) по сети, через порт 9590.
Основано на [k4Mr3/Rotel-RA-1572](https://github.com/k4Mr3/Rotel-RA-1572) и переписано под современный Home Assistant.

## Возможности
- **Настройка через UI** (config flow), YAML не нужен.
- **Только нужные входы.** Отметьте входы, которыми пользуетесь, — в списке источников будут только они.
- **Свои названия входов**, например `Coax 2` → `Стример`. Меняются в любой момент через «Настроить».
- **Шкала громкости до вашего предела:** 100 % в Home Assistant = заданная максимальная громкость усилителя.
- **Подстройка громкости между входами:** тихие и громкие источники звучат одинаково после переключения.
- **Автоматический реконнект:** после перезагрузки или отключения питания усилителя интеграция подключается сама, перезапускать HA не нужно.
- **Актуальное состояние:**
  - сразу после подключения или переподключения запрашивается всё состояние;
  - каждые N секунд (по умолчанию 30) запрашиваются питание, громкость, mute и вход; каждый 10-й опрос запрашивает всё состояние;
  - при выходе усилителя из standby автоматически запрашивается всё состояние.
- **Связанный media player для каждого входа** (заменяет настройку через `universal`, см. ниже).
- **Следование за воспроизведением:** когда связанный плеер начинает играть, усилитель включается, переключается на его вход и ставит другие плееры на паузу.
- **Автовыключение** через N минут без воспроизведения; цифровые входы считаются играющими, пока на них есть сигнал.
- **Фиксированная громкость 100 %** на связанных плеерах (громкость регулируется на усилителе).
- **Объявления (TTS)** через выбранный вход; после них возвращаются прежний вход, громкость и питание.
- **Тембры, баланс, колонки A/B, обход тембров и диммер** — сущности на странице устройства.
- **Сенсоры с информацией об устройстве** (модель, прошивка, IP, MAC, состояние соединения) и кнопка **«Проверить соединение»**.
- **Смена IP-адреса** без повторного добавления интеграции; переименованные связанные плееры подхватываются автоматически, об удалённых появляется предупреждение в «Исправлениях».
- Изменения, сделанные на передней панели или пультом, приходят мгновенно (push).

## Установка

### HACS
1. HACS → ⋮ → *Custom repositories* → `https://github.com/1orgar/ha_rotel_amp`, тип *Integration*.
2. Найдите **Rotel Amplifier (TCP)**, установите и перезапустите Home Assistant.

### Вручную
Скопируйте `custom_components/rotel_amp` в `<config>/custom_components/` и перезапустите HA.

## Настройка
На усилителе установите **POWER OPTION = Quick**, иначе в standby он недоступен по сети.

*Настройки → Устройства и службы → Добавить интеграцию → Rotel Amplifier (TCP)*:

1. Хост, порт (по умолчанию `9590`), название.
2. Используемые входы, максимальная громкость, интервал опроса (`0` — отключить опрос), автовыключение (`0` — выключено).
3. Для каждого входа:
   - название;
   - при желании — связанный media player с опциями «переключаться на этот вход» и «держать громкость на 100 %»;
   - относительная громкость и «не выключать автоматически».

   А также вход и громкость для объявлений.

Всё это можно изменить позже кнопкой **«Настроить»**. Чтобы сменить IP-адрес или порт, используйте **⋮ → «Перенастроить»**: входы, связи и entity_id сохранятся.

## Громкость
Ползунок громкости в Home Assistant охватывает **0…максимальную громкость** усилителя. Например, при максимуме 60: 100 % в HA — это 60 на дисплее усилителя, 50 % — 30, один шаг громкости — один шаг усилителя. Если громкость подняли выше предела с передней панели или пульта, она сразу опускается до предела. Атрибут `amp_volume` показывает значение на самом усилителе.

> При обновлении с 3.x: раньше шкала была фиксированной 0…100. Если максимум меньше 100, автоматизации с `volume_level` теперь дадут более громкий результат.

### Подстройка громкости между входами
У источников разный уровень выхода. Например, стример на 40 звучит так же громко, как Станция на 20. Задайте эту **относительную громкость** для каждого входа (`0` — не использовать). При переключении между двумя входами, у которых она задана, громкость пересчитывается по их отношению:

| Относительная громкость | До переключения | После |
|---|---|---|
| Плеер 40, Алиса 20 | Плеер на 30 | Алиса на 15 |
| | Алиса на 15 | Плеер на 30 |

Если новый вход тише, громкость убавляется до переключения, чтобы не было громкого всплеска. Если громче, она прибавляется после переключения. Результат никогда не превышает максимальную громкость. Громкость не трогается, если включён mute или у одного из входов не задана относительная громкость. Подстройка работает при переключении из Home Assistant и при автоматическом «переключаться на этот вход». При переключении с пульта или передней панели она не срабатывает.

## Связанные плееры
К каждому входу можно привязать другой `media_player`, например стример, умную колонку или Chromecast, подключённые к этому входу. Пока выбран этот вход и усилитель включён, плеер Rotel работает как один общий плеер:

| | откуда |
|---|---|
| питание, громкость, mute, список и выбор входа | **усилитель** |
| состояние (`playing` / `paused` / `idle`), трек, исполнитель, альбом, обложка, позиция, приложение | **связанный плеер** |
| play / pause / stop / next / previous / перемотка / shuffle / repeat / play media / обзор медиа | передаются **связанному плееру** |

Доступные кнопки зависят от возможностей связанного плеера. Если у текущего входа нет связанного плеера или он недоступен, entity работает как обычный усилитель: состояние `on`, команды воспроизведения идут на сам усилитель (USB/Bluetooth). Какой плеер сейчас активен, показывает атрибут `linked_player`.

Это заменяет ручную настройку через `universal`:

```yaml
media_player:
  - platform: universal
    children: [media_player.gostinaia, media_player.yandex_station_xxx]
    active_child_template: >-
      {% if is_state_attr('media_player.rotel_amplifier', 'source', 'Алиса') %} ...
    commands: { select_source: ..., turn_on: ..., turn_off: ... }
    attributes: { volume_level: media_player.rotel_amplifier|volume_level, ... }
```

В интеграции достаточно в **«Настроить»** привязать *Алиса → media_player.yandex_station_xxx* и *Плеер → media_player.gostinaia*.

### Переключение на вход, когда плеер начинает играть
У каждого связанного плеера есть опция **«переключаться на этот вход, когда плеер начинает играть»**. Когда такой плеер начинает играть (его состояние становится `playing`):

1. Все остальные связанные плееры, которые сейчас играют, сразу ставятся на паузу (или останавливаются, если паузу не поддерживают).
2. Если усилитель выключен, он включается. Вход переключается, как только усилитель сообщит `power=on`: пауза всего 0,3 с, без фиксированной задержки.
3. Усилитель переключается на вход этого плеера. Если он проигнорировал команду (так бывает сразу после включения), она повторяется раз в секунду, до 4 раз. Если усилитель уже включён, переключение происходит сразу.

Например, вы включаете музыку на Яндекс Станции: усилитель включается и переключается на *Алису*. Потом запускаете стрим на другом плеере: усилитель переключается на *Плеер*, а Станция встаёт на паузу.

**Без «пинг-понга».** Если в течение 5 с после автопереключения начинает играть другой плеер с этой опцией, усилитель остаётся на первом, а новый ставится на паузу. Каждое автопереключение записывается в **журнал** и вызывает событие `rotel_amp_source_switched` (`source`, `previous_source`, `reason`), которое можно использовать в автоматизациях.

**Только один плеер одновременно.** Если хотя бы у одного входа включена эта опция, играть может только связанный плеер текущего входа. Если играют несколько связанных плееров, остальные ставятся на паузу. Это проверяется при каждой смене входа (в том числе с пульта или передней панели), при включении усилителя и когда начинает играть плеер без этой опции.

### Фиксированная громкость 100 %
У каждого связанного плеера есть опция **«держать громкость плеера на 100 %»**. Громкость регулируется на усилителе, поэтому плеер всегда должен выдавать полный уровень. Если опция включена, интеграция ставит громкость плеера на 100 % и снимает mute. Это происходит при запуске и при каждом изменении состояния плеера, так что если кто-то убавит громкость на самом плеере, она сразу вернётся. Выключенные и недоступные плееры не трогаются.

### Объявления (TTS)
Выберите **вход для объявлений** (например, Яндекс Станцию) и при желании **громкость объявлений** в % шкалы (`0` — не менять). Когда Home Assistant отправляет объявление плееру Rotel (`media_player.play_media` с `announce: true`, так работают TTS и Assist):

1. Усилитель при необходимости включается, переключается на вход для объявлений, и ставится громкость объявлений.
2. Объявление воспроизводится на связанном плеере этого входа.
3. Когда плеер договорит (но не позже чем через 2 минуты), возвращаются прежний вход и громкость. Если усилитель был выключен, он снова выключается.

Пока идёт объявление, «переключаться на этот вход», «только один плеер» и автовыключение не срабатывают.

### Переименованные и удалённые плееры
Если сменить entity_id связанного плеера, связь обновится автоматически. Если связанный плеер удалён, в **Настройки → Исправления** появится предупреждение со списком пропавших плееров. Оно исчезнет, когда вы выберете другие плееры в «Настроить».

## Настройки усилителя
На странице устройства, в разделе *Конфигурация*:

| Сущность | |
|---|---|
| Низкие, Высокие частоты | −10…+10 |
| Баланс | −15 (влево)…+15 (вправо) |
| Колонки A, Колонки B | переключатели |
| Обход тембров | переключатель |
| Яркость дисплея | 0 (ярче всего)…6 |
| Класс PC-USB аудио | 1 / 2 (по умолчанию выключена) |

Пока усилитель выключен, они недоступны. Сервисы `rotel_amp.*` ниже по-прежнему работают.

## Информация об устройстве и проверка соединения
У устройства появляются диагностические сущности:

| Сущность | |
|---|---|
| Модель, Прошивка, Прошивка PC-USB (по умолчанию выключена), IP-адрес, MAC-адрес | читаются с усилителя при каждом подключении; модель, прошивка и MAC также видны на странице устройства |
| Соединение | `connected` / `disconnected` |
| Подключён с, Переподключения, Последняя ошибка соединения, Последнее сообщение (по умолчанию выключено) | диагностика соединения |
| Время ответа | задержка последней проверки соединения, мс |
| Кнопка **«Проверить соединение»** | отправляет `power?` и измеряет время ответа; если усилитель не ответил, показывается ошибка |

При добавлении интеграции проверяется не только то, что порт открыт, но и что устройство действительно отвечает на команды Rotel.

## Автовыключение
**Автовыключение, мин** (`0` — выключено) выключает усилитель, если он включён и ничего не играет заданное время. Таймер запускается заново при каждой остановке воспроизведения и сбрасывается, как только что-то начинает играть или усилитель выключают.

Что считается «играет»:

| Текущий вход | Играет, когда |
|---|---|
| Есть связанный плеер | плеер в состоянии `playing` |
| Цифровой вход (Coax, Optical, USB, Bluetooth, PC-USB) без связанного плеера | усилитель сообщает частоту дискретизации (есть сигнал), например включён телевизор |
| Аналоговый вход (CD, Aux, Tuner, Phono, XLR) без связанного плеера | никогда, поэтому включите для него **«не выключать автоматически на этом входе»** |

Сигнал запрашивается через 1,5 с после каждой смены входа и при каждом опросе. Атрибуты `signal` и `frequency` показывают текущее значение.

## Сервисы
| Сервис | Параметры |
|---|---|
| `rotel_amp.set_bass` / `set_treble` | `level` −10…10 |
| `rotel_amp.set_balance` | `level` −15…15 (минус — влево) |
| `rotel_amp.set_dimmer` | `level` 0…6 |
| `rotel_amp.set_bypass` | `bypass` |
| `rotel_amp.set_speaker_a` / `set_speaker_b` | `enabled` |
| `rotel_amp.set_pcusb_class` | `usb_class` `1` / `2` |
| `rotel_amp.toggle_speaker_a/b`, `toggle_dimmer`, `bass_up/down`, `treble_up/down`, `balance_left/right` | — |
| `rotel_amp.get_current_status` | — (принудительно запросить всё состояние) |

Значения тембров, баланса и других параметров также доступны в атрибутах плеера.
